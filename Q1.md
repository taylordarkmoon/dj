
1. Какие виды коллекций Python вы знаете? Для каких задач предназначен каждый из них?

list (список) — упорядоченная изменяемая коллекция. Для хранения последовательностей (например, список участников).
tuple (кортеж) — упорядоченная неизменяемая коллекция. Для фиксированных данных (например, координаты).
set (множество) — неупорядоченная коллекция уникальных элементов. Для проверки вхождений и удаления дубликатов.
dict (словарь) — коллекция пар «ключ-значение». Для быстрого поиска данных по идентификатору.
2. Чем список отличается от кортежа?
Список (list) можно изменять после создания (добавлять, удалять элементы), он объявляется в квадратных скобках []. Кортеж (tuple) изменить нельзя, он объявляется в круглых скобках ().

3. В каких случаях удобно использовать множество?
Когда нужно быстро проверить, есть ли элемент в коллекции, или когда нужно гарантировать уникальность элементов (например, собрать уникальные роли пользователей).

4. Почему словари называются коллекцией пар «ключ – значение»?
Потому что данные в них хранятся не по индексу (как в списке), а по уникальному ключу. Например, {"id": 1, "name": "Митап"}. Это позволяет мгновенно находить нужное значение по его имени.

5. Чем цикл for отличается от цикла while?
for используется, когда мы перебираем элементы коллекции (или используем range()), и мы заранее знаем количество итераций. while выполняется до тех пор, пока условие истинно, и используется, когда количество повторений неизвестно (например, главное меню программы).

6. Для чего используется функция range()?
Для генерации последовательности чисел. Чаще всего используется в циклах for: range(5) сгенерирует 0, 1, 2, 3, 4.

7. Как организовать перебор элементов словаря в цикле?
С помощью метода .items(): for key, value in my_dict.items():. Если нужны только ключи — перебираем сам словарь или используем .keys(), если только значения — .values().

8. Для чего используются операторы break и continue?
break полностью прерывает и выходит из цикла. continue пропускает текущую итерацию и переходит к следующей.

9. Как объявить функцию в Python? Что возвращает функция без оператора return?
Объявление: def имя_функции(параметры):. Если в функции нет return, она по умолчанию возвращает None.

10. Чем позиционные параметры отличаются от именованных?
Позиционные передаются в том порядке, в котором они указаны в функции (func(10, 20)). Именованные (keyword arguments) передаются с указанием имени переменной (func(a=10, b=20)), их порядок не важен.

11. Что такое область видимости переменной?
Это место в программе, где переменная доступна. Переменные, созданные внутри функции, — локальные (видны только там). Переменные вне функций — глобальные.

12. Что такое docstring и для чего он нужен?
Это строка документации, которая пишется сразу после объявления функции/класса в тройных кавычках """...""". Она нужна для описания того, что делает функция, какие принимает аргументы и что возвращает (помогает другим разработчикам и IDE).

3. Что такое модуль Python?
Это файл с расширением .py, содержащий код (функции, переменные, классы), который можно импортировать в другие программы.

14. Чем импорт модуля отличается от импорта отдельного объекта из модуля?
import math импортирует весь модуль (обращение: math.sqrt()). from math import sqrt импортирует только функцию (обращение: sqrt()).

15. Что такое пакет и для чего нужен файл __init__.py?
Пакет — это папка с модулями. Файл __init__.py (даже пустой) говорит Python, что эта папка является пакетом, и позволяет импортировать из нее модули.

16. Для чего используется конструкция try/except?
Для обработки исключений (ошибок). Код в try выполняется, и если возникает ошибка, программа не падает, а переходит в блок except, где ошибку можно обработать.

17. Чем блок finally отличается от блока else?
else выполняется только в том случае, если в try не было ошибок. finally выполняется всегда (и при ошибке, и без нее), обычно используется для закрытия файлов или соединений.

18. Для чего используется оператор raise?
Для принудительного вызова (генерации) исключения. Например, если пользователь ввел отрицательный возраст, мы можем сделать raise ValueError("Возраст не может быть отрицательным").

19. Зачем закрывать файл после работы с ним?
Чтобы освободить оперативную память и системные ресурсы, а также чтобы гарантировать, что все данные из буфера были записаны на диск (не потерялись).

20. Какие преимущества дает контекстный менеджер with?
Он автоматически закрывает файл после выхода из блока with, даже если внутри произошла ошибка. Это делает код безопаснее и короче (не нужно писать file.close()).

21. Что такое интроспекция? Какие функции Python для нее используются?
Это способность программы исследовать типы и свойства объектов во время выполнения. Функции: type() (узнать тип), dir() (список атрибутов), hasattr() (есть ли атрибут), id() (адрес в памяти).

22. Что такое пространство имен?
Это система, которая сопоставляет имена переменных и функций с объектами в памяти. Благодаря ей в разных модулях могут быть функции с одинаковыми именами, и они не будут конфликтовать.

23. Что такое итератор и генератор?
Итератор — объект, который позволяет перебирать элементы по одному (с помощью next()). Генератор — это упрощенный способ создания итератора с помощью функции с оператором yield.

24. Для чего используется оператор yield?
Он используется в генераторах. В отличие от return, который завершает функцию, yield приостанавливает ее, возвращает значение и запоминает состояние, чтобы при следующем вызове продолжить с того же места.

25. Что такое лямбда-функция и где она применяется?
Это анонимная (безымянная) функция, состоящая из одного выражения: lambda x: x * 2. Чаще всего применяется для коротких операций, например, для указания ключа сортировки: sort(key=lambda x: x["price"]).

26. Что такое аннотации типов и как они оформляются?
Это указание типов данных для аргументов функции и ее возвращаемого значения. Оформляются через двоеточие и стрелку: def func(a: int, b: str) -> bool:. Они не влияют на работу программы, но помогают IDE и разработчикам находить ошибки.

27. Для чего используется линтер flake8 и как выполнить проверку?
Flake8 проверяет код на соответствие стандарту оформления PEP 8, ищет неиспользуемые импорты и переменные. Запускается из терминала в папке проекта командой: flake8.

28. Какие требования к оформлению кода предъявляются в рамках ПР2?
Соблюдение PEP 8 (отступы в 4 пробела, не более 79 символов в строке), осмысленные имена переменных, отсутствие неиспользуемого кода, разделение на логические модули.

29. Как устроен автоматизированный тест pytest и что проверяет оператор assert?
Тест — это функция, начинающаяся с test_. Внутри нее вызывается тестируемая функция, а результат проверяется через assert. Если выражение в assert истинно — тест пройден. Если ложно — выбрасывается AssertionError и тест считается упавшим.

30. Как запустить тесты и как интерпретировать результат?
Запуск: команда pytest в терминале. Результат: зеленые точки или слово passed означают успех. Красная F — тест провален (ошибка в логике), E — ошибка выполнения (например, синтаксис).
