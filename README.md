# Сервис мероприятий «Event»

## Назначение
Приложение представляет собой платформу для организации и посещения мероприятий. Оно позволяет организаторам создавать события, выбирать площадки, а участникам — регистрироваться на них и узнавать стоимость билета.

## Целевая аудитория
- Организаторы мероприятий (конференции, мастер-классы, встречи).
- Участники (гости, слушатели), желающие посещать события.
- Администраторы площадок (предоставляют помещения).

## Предметная область
Организация и проведение офлайн-мероприятий. Учет доступных площадок, контроль количества мест и регистрация участников.

## Основные сущности
- **Пользователь** (имя, роль: организатор/участник).
- **Мероприятие** (название, дата, базовая стоимость билета).
- **Площадка** (название, адрес, максимальная вместимость).
- **Участник** (связь пользователя с конкретным мероприятием, статус регистрации).

## Основные функции
- Проверка доступности мест на мероприятии (сравнение зарегистрированных участников с вместимостью площадки).
- Расчет итоговой стоимости билета с учетом скидки за раннюю регистрацию.
- Формирование приветственного сообщения и проверки прав пользователя в зависимости от его роли.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL) для хранения сущностей;
- реализация личного кабинета пользователя и системы аутентификации;
- разработка REST API для интеграции с внешними календарями;
- контейнеризация приложения (Docker);
- настройка CI/CD.
