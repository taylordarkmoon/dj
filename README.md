
# Сервис мероприятий «EventHub»

Консольное приложение для управления мероприятиями, площадками и регистрацией участников.

## Возможности
- просмотр и поиск мероприятий;
- проверка вместимости площадок;
- проверка доступности мест на мероприятие;
- добавление и отмена регистраций участников;
- сохранение данных в JSON.

## Структура проекта
- `main.py` — точка запуска и меню;
- `events.py` — работа с мероприятиями;
- `venues.py` — работа с площадками;
- `registrations.py` — работа с участниками;
- `storage.py` — сохранение и загрузка данных (JSON);
- `utils.py` — вспомогательные функции (безопасный ввод);
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Запуск программы
python main.py
