. Какие основные типы данных используются в Python?
В Python множество типов данных, но базовыми (встроенными) являются:

Числовые: int (целые числа), float (числа с плавающей точкой/дроби), complex (комплексные числа).
Текстовые: str (строки).
Логические: bool (True/False).
Последовательности (коллекции): list (списки), tuple (кортежи), range (диапазоны).
Множества: set, frozenset.
Словари: dict.
Специальный тип: NoneType (обозначает отсутствие значения).
2. Чем отличаются int, float, str и bool?

int — целые числа без дробной части (например, 5, -100). Используется для подсчетов.
float — числа с плавающей точкой, имеющие дробную часть (например, 3.14, -0.5). Используется для точных измерений, научных вычислений.
str — строки, текст, заключенный в кавычки (например, "Привет", 'Python'). Используется для работы с текстом.
bool — логический тип, принимающий только два значения: True (истина) или False (ложь). Используется в условиях и проверках.
3. Для чего используется преобразование типов?
Преобразование типов (кастинг) используется, когда нужно изменить тип данных переменной для выполнения определенных операций. Например, чтобы сложить число, введенное пользователем (которое по умолчанию является строкой str), с другим числом, нужно преобразовать его в int или float с помощью функций int(), float(), str() или bool().

4. Какие операции можно выполнять со строками?
Строки в Python поддерживают множество операций:

Конкатенация (сложение): "Hello" + " " + "World" -> "Hello World".
Дублирование (умножение на число): "Hi" * 3 -> "HiHiHi".
Доступ к символам по индексу: "Python"[0] -> "P".
Срезы (получение подстроки): "Python"[1:4] -> "yth".
Встроенные методы: .upper() (в верхний регистр), .lower() (в нижний), .replace() (замена), .split() (разбиение на список), .strip() (удаление пробелов по краям) и многие другие.
5. Какие операторы сравнения используются в Python?

== (равно)
!= (не равно)
> (больше)
< (меньше)
>= (больше или равно)
<= (меньше или равно)
Результатом любого сравнения всегда является логическое значение True или False.
6. Для чего используется конструкция if?
Конструкция if используется для реализации ветвления в программе. Она позволяет выполнять определенный блок кода только в том случае, если заданное условие истинно (True).

7. В чем различие между if, elif и else?

if — проверяет первое условие.
elif (else if) — проверяет следующее условие, только если предыдущие условия оказались ложными (False). Можно использовать несколько elif.
else — выполняется, если ни одно из условий if или elif не оказалось истинным. Это "страховочный" вариант.

9. Для чего используются логические операторы and, or и not?

and: Возвращает True, если оба условия истинны.
or: Возвращает True, если хотя бы одно из условий истинно.
not: Инвертирует значение (превращает True в False и наоборот).
10. Что такое модуль Python?
Модуль — это файл с расширением .py, содержащий код на Python (функции, классы, переменные). Модули позволяют разбивать программу на логические части и переиспользовать код.

11. Для чего используется import?
Ключевое слово import используется для подключения модулей (как встроенных в Python, так и сторонних или собственных) в текущую программу, чтобы получить доступ к их функциям и объектам.

12. Чем импорт модуля отличается от импорта отдельного объекта из модуля?

import math — импортирует весь модуль. Чтобы использовать функцию, нужно писать math.sqrt() (указывать имя модуля).
from math import sqrt — импортирует только конкретную функцию из модуля. В коде можно писать просто sqrt(). Это экономит память и делает код короче, но может привести к конфликту имен, если импортировать много всего.

3. Для чего используется виртуальное окружение Python?
Виртуальное окружение (venv) создает изолированную среду для конкретного проекта. Это нужно, чтобы зависимости (сторонние библиотеки) разных проектов не конфликтовали друг с другом. У каждого проекта есть свой набор пакетов.

14. Что такое IDE?
IDE (Integrated Development Environment) — интегрированная среда разработки. Это программа, которая объединяет в себе текстовый редактор, компилятор/интерпретатор, отладчик и другие инструменты для удобной разработки кода (например, PyCharm, VS Code).

15. Для чего используется Git?
Git — это распределенная система контроля версий. Она используется для отслеживания изменений в коде, сохранения истории разработки, а также для командной работы над проектом (возможность сливать изменения, откатываться к старым версиям).

16. Что такое репозиторий?
Репозиторий — это хранилище проекта. В нем хранятся все файлы проекта, а также вся история их изменений (коммиты). Репозиторий может быть локальным (на вашем компьютере) или удаленным (на сервере, например, GitHub).

17. Что такое commit?
Commit (коммит) — это снимок (фиксация) состояния файлов в репозитории на определенный момент времени. Каждый коммит имеет уникальный хеш, автора, дату и сообщение, описывающее внесенные изменения.

18. Для чего нужен .gitignore?
Это служебный файл, в котором перечисляются файлы и папки, которые Git должен игнорировать. Обычно туда добавляют виртуальное окружение (venv/), кэш Python (__pycache__/), файлы с секретными данными (.env) и файлы настроек IDE (.idea/).

19. Для чего нужен README.md?
Это главный файл документации проекта. Он первым открывается при просмотре репозитория. В нем описывается, что делает проект, как его запустить, какие технологии используются, кто автор и т.д.

20. Что такое отладка?
Отладка (debugging) — это процесс поиска и устранения ошибок в программном коде.

21. Что такое breakpoint?
Точка останова (breakpoint) — это специальный маркер в коде (обычно устанавливается в IDE), при достижении которого выполнение программы приостанавливается. Это позволяет программисту заглянуть "внутрь" программы.

22. Для чего используется пошаговое выполнение программы?
Пошаговое выполнение используется при отладке. Оно позволяет выполнять код строка за строкой, наблюдая за тем, как меняются значения переменных, и проверяя, правильно ли работает логика программы на каждом этапе.
